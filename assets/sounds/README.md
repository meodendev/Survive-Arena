# Sound Assets

Place your sound files here:

- shoot.mp3 - Sound when shooting
- explosion.mp3 - Bomb explosion sound
- pickup.mp3 - When picking up items
- win.mp3 - When winning a round
- bgm.mp3 - Background music

## Format
- MP3 or WAV format
- Short sounds (under 1 second for effects)
- BGM should be loopable

## Fallback
If sounds are not available, the game will use Web Audio API synthesized sounds.
